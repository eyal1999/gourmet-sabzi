# Gourmet Sabzi logo files

The logo is "The Pot" (הסיר): a Persian stew pot with an engraved band and an herb leaf on the lid.

## Which file to use

| Where | File |
|---|---|
| Instagram, Facebook and Wolt profile picture | `profile-picture.png` (1080 × 1080) |
| Menus, flyers, anything printed on a light background | `logo-stacked-on-light.svg` or `logo-horizontal-on-light.svg` |
| Signs or print on a dark green background | `logo-stacked-on-dark.svg` or `logo-horizontal-on-dark.svg` |
| Stamps, stickers, bags (one color) | `logo-mark-black.svg` (the print shop can change the color) |
| The pot alone, on light or dark backgrounds | `logo-mark-green` / `logo-mark-gold` (`.svg` or `.png`) |
| Website browser tab and phone home screen | `favicon.svg`, `favicon-32.png`, `apple-touch-icon.png` (already linked from `index.html`) |

- **SVG** files are vector: they stay sharp at any size, from a sticker to a sign. Give these to print shops and designers. The lettering is already converted to shapes, so no fonts need to be installed.
- **PNG** files have transparent backgrounds (except the profile picture and the phone icon) and are for apps, documents and social media.
- Files marked `on-light` are for white or cream backgrounds; `on-dark` are for dark green or dark photos.
